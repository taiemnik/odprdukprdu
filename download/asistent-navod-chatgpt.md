# ChatGPT · Custom GPT — návod nasazení

## 1. Co otevřít

1. **chatgpt.com** → **Explore GPTs** → **Create** (vpravo nahoře).
2. Zvol **Configure** (ne Assistant).

## 2. Pole po poli

| Pole | Co vyplnit |
|------|------------|
| **Name** | `Asistent na prd` |
| **Description** | Mechanický asistent, který promění váš neurčitý název ("prd") v PRD prompt pro AI kódery. Bezcitně eliminuje zbytečné funkce. Pro Vibecoding komunitu. |
| **Instructions** | Celý obsah z tlačítka **Pokyny** |
| **Conversation starters** | 4 řádky níže |

**Conversation starters** (zkopíruj přesně):

```
Mám nápad na aplikaci...
Chci postavit něco jako Notion, ale jednodušší.
Nevím kde začít s Vibecodingem.
Jak z mého nápadu udělat funkční Artefakt v Claude?
```

## 3. Co zaškrtnout (Capabilities)

- ✅ **Code Interpreter & Data Analysis**
- ☐ DALL-E Image Generation
- ☐ Web Search

## 4. Uložit a test

1. **Save** → **Only me** nebo **Anyone with a link** (pro festival).
2. Nový chat s GPT → napiš nebo klikni starter **Mám nápad na aplikaci...**

**Správně:** úvodní monolog + Fáze 1 (3 otázky).

**Špatně:** okamžitý kód nebo obecný ChatGPT bez role.

## 5. Tip

Instructions vlož až po zkopírování z **Pokyny** — ne celý soubor s nadpisy NAME/DESCRIPTION.
